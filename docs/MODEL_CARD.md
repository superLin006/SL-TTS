# Model card — pinyin224

## 基本

- 架构：Piper/VITS medium
- 参数量：约 15M（生成器）+ 判别器，训练总参数约 70M
- 采样率：22,050 Hz
- 音素：App g2pW/pinyin token 集（73 个 token，含声调 1–5、词边界与标点）
- 教师：Kokoro v1.1-zh `zf_001`（Apache-2.0 模型权重，需自行下载）
- 训练数据：11,725 句 / 约 20h，Kokoro 合成语音
- 训练：从零训练，pinyin 标签，batch 16，LR 5e-5；本次验收 checkpoint 为 epoch 224/300

## 数据构成

- v2 自然对话：9,726 句 / 14.3h，77 场景、33 类数字、25 组多音字
- 长句 SFT：2,000 句自然长句（35–80 字），补充 400+ 音素样本
- 教师短语修正：用 App lexicon 的 47k 短语表覆盖 Kokoro 的 pypinyin 读音，修正“还书、系鞋带、种花、饕餮、蹙眉”等

## 客观评测

100 词多音字/生僻词（ASR 词面命中）：

- full float pinyin224：缺 7（参差 + 龃龉/觊觎/踟蹰/迤逦/恣睢/忸怩）
- 长短句时长 MAE：长句 0.094、短句 0.232（v2 espeak 为 0.141/0.250）
- 长句 >600 音素时长比：0.928（espeak 0.864）

## 已知限制

- 训练集中未出现的生僻词（龃龉、觊觎、踟蹰等）仍可能读错；这是词表/数据覆盖问题。
- 教师与学生的 tone sandhi 处理不完全一致；连续三声、一/不的变调仍可能有细微差异。
- 教师音频为合成数据，韵律多样性受 Kokoro 限制；继续提升需要更多真实或更高质量教师数据。
- 当前 lexicon/tokens 源自 `zh_CN-xiao_ya-medium`（BZNSYP 非商用条款），发布或商用前必须确认授权或替换为自建词表。
